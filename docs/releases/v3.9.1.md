# BYDMate 3.9.1 — диагностика ошибок и подключение ADB-helper

## Диагностика автомобиля — экспериментально

В **Настройки → Сервис и данные → Диагностика ошибок** добавлены:

- Ручное сканирование блоков автомобиля, активные, сохранённые и ожидающие подтверждения коды.
- Сохранение последнего завершённого результата с датой и числом ответивших блоков.
- Расшифровки из оригинального BYDMate; описания доступны на английском. Совпадения с похожими моделями отмечаются отдельно.
- Отправка диагностического отчёта в Telegram-бота, настроенного в «Интеграциях». Отправка только по кнопке, без автоматической рассылки.
- Стирание ошибок по блокам или всех найденных — после подтверждения и с повторным чтением.

Для сканирования нужны свежие данные и положение **P**. Для стирания дополнительно требуется достоверно нулевая скорость и скан не старше 10 минут. Потеря ответа не считается успешным стиранием: перед повтором требуется новая проверка. Стирание не устраняет неисправность, а активные ошибки могут вернуться. Перед стиранием сохраните отчёт.

**Поддержка диагностического протокола оригинала на конкретной прошивке DiLink 2 ещё не подтверждена.** Работающая штатная `diagnosticsrv` не гарантирует поддержку всех запросов BYDMate. Недоступность службы и отсутствие ответов не выдаются за «ошибок нет». Начинайте только с чтения на стоящей машине.

## Исправление ADB-helper

- Перенесён резервный Binder-канал из оригинального BYDMate: helper может передать соединение непосредственно приложению, когда прошивка запрещает регистрацию сервиса в ServiceManager.
- Соединение защищено случайным токеном запуска, проверкой дескриптора и UID приложения. SELinux не отключается, root не требуется.
- Исправлена обработка `INTERFACE_TRANSACTION`, из-за которой полученное соединение отклонялось как `descriptor_mismatch`.
- Добавлено восстановление соединения после перезапуска приложения, подтверждение клиента и проверка версии живого helper.
- Диагностические команды запуска не повторяются автоматически после потери Binder-ответа.

На физической Чайке подтверждены отказ `addService` и запуск резервного канала `READY via=broadcast`. **Окончательное принятие соединения после исправления дескриптора ещё не проверено:** ADB-туннель обрывался при передаче APK. Этот релиз опубликован для установки через GitHub и продолжения проверки. На первом холодном запуске тестовой сборки также наблюдался тайм-аут старта приложения; повторный запуск открывал его.

## Климат DiLink 2

- Нормальное включение климата вместо режима одной вентиляции; у владельца подтверждён горячий воздух при заданных 33 °C.
- Температура, мощность вентилятора, питание климата и направление потока используют отдельные команды с чтением результата.
- Поддерживаются сочетания направлений «лицо / ноги / стекло»; они не смешиваются с отдельной программой размораживания F.
- Для климатических команд снято ожидание P; нужны готовый ADB и свежие данные. Диагностические ограничения P и нулевой скорости сохранены.
- Команды подогрева сидений не отправляются для этой комплектации Seagull.
