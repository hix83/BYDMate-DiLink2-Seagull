# BYDMate 3.9.4 — расшифровки ошибок Чайки на русском

## Исправлено

В 3.9.3 сканер успешно читал коды, но описания могли отсутствовать: Чайка сообщает модель AutoType 148, для которой нет сопоставленного руководства в таблице оригинала; класс новых блоков также не всегда известен. Строгий подбор описаний в этих условиях возвращал пустой результат.

Для проверенной CANFD-прошивки добавлены справочные описания наблюдавшихся сочетаний адреса и кода:

| Адрес | Код | Описание |
| --- | --- | --- |
| 0x741 | B1AB7-00 | Ошибка регистрации в сети |
| 0x741 | U0247-87 | Ошибка связи с TCP-сервером |
| 0x720 | B2A4B-92 | Привод рециркуляции не достигает заданного положения |

Тексты взяты из поставляемого справочника BYD, русский перевод отображается в приложении и диагностическом Telegram-отчёте. Описания помечаются как справочные; они объясняют код, но не устанавливают физическую причину неисправности. В других прошивках и для других адресов/кодов эти описания автоматически не подставляются. Точное описание из руководства модели, если оно найдено, сохраняет приоритет.

## Проверка

На установленной 3.9.3 проверен сохранённый скан: 19/19 ответов, 2 активных и 1 сохранённая ошибка. По кнопке «В Telegram» приложение подтвердило «Отчёт отправлен в Telegram». Это проверка существующей отправки с кодами; новые русские описания проверены отдельно тестом формирования отчёта на реальных данных AutoType 148. После этого пропал Remote ADB, новый интерфейс на ГУ ещё требует проверки после обновления.

Профиль из 19 адресов и учёт дубликатов сохранены. **Стирание остаётся полностью отключённым.**

Проверка сборки: **3029 тестов, 0 ошибок, 2 пропущены**. Подпись совпадает с предыдущими версиями нашего форка, ARM64 проверена.

## Обновление

Версия **3.9.4**, Android `versionCode` **394**. Прежние ARM64, Android 9+, подпись и канал `physical-debug`.

В приложении: **Настройки → Приложение → Проверить обновления**. Установите поверх текущей версии, удаление приложения не требуется. После обновления откройте **Настройки → Сервис и данные → Диагностика ошибок → Результат** — расшифровки применятся и к сохранённому скану. Затем можно отправить новый отчёт кнопкой **«В Telegram»**.

Файлы `BYDMate-v3.9.4-physical-debug.apk` и `BYDMate-v3.9.4.apk` содержат одну сборку. Контрольные суммы — в `v3.9.4.sha256`.
